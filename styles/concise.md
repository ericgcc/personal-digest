# Concise
A fast per-source digest designed for scanning. Keep each source separate and reduce it to the smallest useful summary without losing its central value.
## Summary mode
Produce one compact entry for each reviewed source worth retaining.

Do not synthesize different sources into a shared narrative. Each entry should represent only the source it summarizes.

For each source, identify the one idea, development, technique, argument or takeaway that best explains why the source may be worth the reader’s attention.

Prefer signal over coverage. Do not attempt to preserve every topic contained in a source.

If several sources cover the same story or idea, summarize each independently but avoid repeating unnecessary background. Do not merge them; source independence is part of this style.

## Length and density

Aim for approximately 10–20 seconds of reading per retained source.

Use one compact paragraph, typically 40–80 words.

Shorter is better when the source contains only one simple idea. Use additional detail only when necessary to preserve an important qualification, limitation or consequence.

Every sentence should contribute information. Remove introductions, filler, transitions and obvious context aggressively.

## Required structure

For each retained source include:
### Source or publication name
**Article or item title**

One concise paragraph containing:
- The central idea or development.
- The most important supporting detail when needed.
- Why it matters, only when this is not already obvious from the summary.
- 
Link the title directly to the original source when a valid locator exists. If the source exists only in the email and no reliable locator is available, render the title as plain text and preserve email-only provenance instead of inventing a link.

Do not add bullet lists, thematic sections, editor’s notes or a final synthesis.
## Selection and filtering
Retain substantive sources even when their value is modest; Concise is primarily a compression mode rather than an editorial synthesis mode.

Omit or clearly de-emphasize material that is only:
- Promotional or sponsored content.
- Administrative or welcome material.
- Duplicate content within the same source.
- Empty link collections with no meaningful content available.
- Material with too little substance to summarize reliably.

When a source contains several unrelated items, select only the strongest one or two rather than producing a mini-roundup.
## Fidelity

Preserve the source’s actual meaning, level of certainty and important caveats.

Do not introduce conclusions, recommendations or implications that the source does not reasonably support.

Do not make an ordinary update sound important merely to create a stronger summary.

If the available content is incomplete, summarize only what is actually supported.
## Ending rules

Finish after the final source entry.

Do not include:

- A Big Picture section.
- Cross-source trends.
- A concluding recap.
- Generic takeaways.
- A final source catalog.
## Quality control

Before returning the digest, verify that:

- Every retained source remains clearly separate.
- Each entry can be scanned in seconds.
- The highest-value idea appears early.
- No entry has become a detailed article summary.
- Repeated background has been removed.
- Every available source link points to the correct original source, and email-only sources are not given fabricated links.
- No unsupported editorial conclusions have been introduced.
