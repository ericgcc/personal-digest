# Tasks

Three phases, each independently verifiable and small enough for one focused Builder cycle. Phases are ordered by dependency: Phase 2 consumes Phase 1's catalogue loading; Phase 3 consumes Phase 2's findings. Every phase ends with the full offline test suite green and the behavioral gate passing.

## Scope boundaries

- Do not add stages, executors, judge calls, or LLM calls.
- Do not edit the WOPS project; if an integration blocker is found, stop and report it with evidence.
- Do not embed anti-pattern vocabulary in generic code (generalization firewall applies).
- Do not regenerate the frozen prompt baseline; classify changes in `behavioral-gate.json` instead.
- Do not run paid replays without explicit user authorization.
