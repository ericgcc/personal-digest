# Retirement of the standalone Copy Edit stage

The prior Copy Edit stage was retained temporarily for controlled comparison, not as a
permanent part of the Synthesis MAX architecture. In the 2026-10-10 C1/C2 replays,
C1 lost load-bearing explanations and C2 made mostly cosmetic changes, including a
weakened attribution. Both needed targeted repair. These observations motivate
removal of the separate model call; they do not by themselves prove the new output
is better.

Writer Revision now owns the full prose-quality finish (clarity, naturalness,
grammar, consistency, flow, concision and preservation), and receives the
**existing Naturalness Contract**, including its whole-edition pattern audit.
Reader Review uses absolute evaluation of the resulting revision, not a
before/after comparison, and can request one evidence-bounded targeted repair
for a major or critical issue. Publication Verify remains deterministic.

Historical run artifacts, frozen fixtures, and the original editing contracts
should remain available for audit; they are no longer active runtime stages.
Acceptance still requires a new controlled replay and manual editorial reading.
